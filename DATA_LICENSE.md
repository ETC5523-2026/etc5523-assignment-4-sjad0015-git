# Data licence and attribution

## Data source

The ball-by-ball cricket data used in this package
is sourced from Cricsheet.

Website: https://cricsheet.org/

## Data licence

Cricsheet match data (JSON, YAML and CSV) is made
available under the Open Data Commons Attribution
License (ODC-By) 1.0.

Licence: https://opendatacommons.org/licenses/by/1-0/

The WPL bowling dataset included in this package is
derived from Cricsheet data through filtering,
aggregation and calculation of bowling statistics.

Cricsheet is credited as the original data source.
