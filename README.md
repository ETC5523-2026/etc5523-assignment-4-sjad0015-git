# wplbowling

Explore bowling performance in the Women's Premier League (WPL).

## Purpose

This package helps cricket coaches and analysts investigate which bowlers perform most effectively across different phases of a T20 innings.

## Data

WPL bowling statistics derived from Cricsheet ball-by-ball data.

Source: <https://cricsheet.org/>

## Installation

``` r
devtools::install_github("sjad0015-git/wplbowling")
```

## Launch the app

``` r
library(wplbowling)
run_app()
```
